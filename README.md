# eda-superstore-sales-analysis # Exploratory Data Analysis (EDA) - Retail Sales Dataset

## Project Overview
This project performs comprehensive exploratory data analysis on retail transaction data using Python, Pandas, and Matplotlib/Seaborn.

## Objectives
- Clean raw retail data and handle missing values
- Analyze sales trends across product categories and regions
- Perform customer segmentation based on purchase frequency and monetary value
- Visualize top-performing products and profit margins

## Tech Stack
- **Languages:** Python, SQL
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / Google Colab

## Key Insights
- Identified high-margin vs high-volume product categories.
- Seasonal trends show peak revenue during Q4.
- Recommended inventory optimization strategies based on regional demand patterns.
